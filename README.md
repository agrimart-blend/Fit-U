# Fit U

Public privacy and account support website for Fit U.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Wait for GitHub to show the successful deployment URL.

Expected public pages:

- https://agrimart-blend.github.io/Fit-U/
- https://agrimart-blend.github.io/Fit-U/privacy-policy.html
- https://agrimart-blend.github.io/Fit-U/account-deletion.html

## Support email

The support email has intentionally been left empty. The email request option is unavailable until a monitored support email is added. Before using the account deletion URL for a Play Console submission, provide an external account deletion request route that works without reinstalling the app.

To enable email support, replace the blank support-email spans in both pages with your public address, and replace the unavailable email option on the account deletion page with a working mailto link. Monitor requests, verify account ownership, process deletion through authorized backend tools, and reply to users.

These static pages do not directly authenticate users or execute account deletion. The in-app deletion route remains Profile → Delete account.

## Files

Plain HTML, CSS and decorative SVG. No build command, API keys, app source code or signing credentials are needed. White and green appearance is preserved regardless of device dark mode.
